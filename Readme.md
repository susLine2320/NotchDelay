# ノッチ表示灯遅延プラグイン
ノッチ表示灯を遅延表示するプラグインである。かつて公開されていた`Meter_digital.dll`と同様の機能を備えている。

## 設定番号
### Panelインデックス
設定により任意に設定可能。
### Soundインデックス
設定なし
### Beaconインデックス
設定なし
### Signalインデックス
設定なし
### SWインデックス
設定なし
#### 設定ファイル
ファイル名は`NotchDelay.xml`とし、本体のファイル名に依存しない。設定値とデフォルト値は以下の通り。
| Field                | Brief           | Value |
|----------------------|-----------------|-------:|
| **[Core]**               |                 |       |
| Delay        | ノッチ出力を遅らせる時間[ms][1]         | 750    |
| Lag       | ノッチ表示灯を更新する間隔[ms][2]         | 100    |
| HbkNotch               | 抑速ブレーキノッチ数[3]        | 25    |
| **[Panel]**[4]                |                 |       |
| Power | 力行ノッチ表示灯インデックス[5]           | 216   |
| Brake | ブレーキノッチ表示灯インデックス           | 215   |
| Reverser | レバーサーインデックス[6]           | -1   |

1. `Meter_digital.dll`と同様の機能。
2. `NotchNumber.dll`と同様の機能。
3. マスコンハンドルを逆回しするタイプのもの。B1抑速は含まない。
4. 設定値を負とすると出力されない。
5. 表示値xはHbkNotch設定値aとして`P(x+a)`,`H(-x+a)`,`N(a)`
6. 表示値は後退`0`、中立`1`、前進`2`

## 著作権
何かしらのライセンスを設定しているわけではないが、単体での再配布は不可。
車両データに同封する場合、事前連絡不要。なお当方の把握のため、事後に必ず連絡すること。
